# Ejemplos

Tres puntos de partida. Cada uno trae la configuración que cambia, unas reglas para el reactor y un esqueleto de prompt para tu agente. El esqueleto es tuyo: ninguno es el prompt de GAIA.

| | Ejemplo | Gesto | Copiar |
|---|---|---|---|
| 01 | [Cabina](cabina) | Descolgar un auricular | `cp examples/cabina/rules.toml device/rules.toml` |
| 02 | [Objeto que escucha](objeto) | Tocar o acercarse | `cp examples/objeto/rules.toml device/rules.toml` |
| 03 | [Sala](sala) | Entrar | `cp examples/sala/rules.toml device/rules.toml` |
